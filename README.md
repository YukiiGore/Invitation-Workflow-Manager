# Invitation Workflow Manager

Desktop application for managing personalized invitation assets and captions.

## Features

- 🖼 PNG Preview
- 👤 Automatic username detection from filename
- ✨ Dynamic template replacement
- 📋 Copy caption
- 📂 Reveal image in Explorer
- 📈 Progress tracking
- 💾 Resume session

## No Discord API

Invitation Workflow Manager does **not** automate Discord or use user tokens.

It assists manual workflows by organizing invitation assets and generating personalized captions.
